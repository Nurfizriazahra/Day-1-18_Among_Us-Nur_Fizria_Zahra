# Day-1-Among_Us-NurFizriaZahra
Day 1 TIK Mengajar - Workshop Mempelajari Git &amp; Github

Nama Lengkap : Nur Fizria Zahra
Deskripsi respository : 
Respository adalah ruang penyimpanan digital yang berisi kumpulan file, kode program, dan dokumen yang berkaitan dengan suatu proyek.
Tujuan dan kegunaan respository : 
Tujuan dan kegunaan respository adalah untuk mempermudah proses pengembangan proyek melalui pengelolaan file, pemantauan riwayat perubahan, serta mendukung kerja sama antaranggota agar pengerjaan lebih terorganisasi.

Rangkuman materi :
Pada TIK mengajar Day 1 materi yang disampaikan membahas tentang penggunaan AI dan pengenalan Git & GitHub. Pertama membahas Prompt Engineering, yaitu bagaumana cara kita memberikan instruksi kepada AI agar hasil yang diberikan lebih sesuai dengan apa yang kita mau. Dijelaskan juga dalam membuat prompt AI terdapat beberapa hal yang perlu diperhatikan, seperti role, task, context, dan format. 

Selain itu, workshop membahas tentang Git dan GitHub. Git merupakan alat untuk mencatat dan mengelola perubahan pada file atau proyek, sedangkan GitHub merupakan platform online untuk menyimpan repository dan melakukan kolaborasi. Pada workshop juga diperkenalkan dengan beberapa istilah seperti repository, commit, branch, dan pull request, serta beberapa perintah dasar Git.

Poin-poin penting :
1. Membuat prompt AI harus memberikan instruksi yang jelas agar hasil yang diberikan sesuai 
2. Mengetahui perbedaan Git dan GitHub serta fungsinya
3. Repository merupakan tempat penyimpanan proyek.
4. Mengetahui bahwa GitHub dapat menyimpan proyek secara online dan memudahkan kolaborasi.

Pendapat pribadi :
Menurut saya, workshop hari pertama cukup menarik karena dijelaskan materi yang sebelumnya belum terlalu saya pahami, terutama mengenai Git dan GitHub. Awalnya saya tidak mengetahui apa itu git dan github serta fungsi keduanya. Materi tentang prompt AI juga cukup bagus, Saya jadi mengetahui kalau cara kita memberikan instruksi sangat berpengaruh dengan hasil yang diberikan AI. Untuk kegiatan proyeknya, saya merasa masih kurang terlalu memahami di beberapa materi, terutama pada materi bagaimana cara kita meminta AI untuk menginstal aplikasi. Akan tetapi, kegiatan di hari pertama ini cukup menambah pengetahuan dan memberikan gambaran tentang bagaimana membuat proyek sederhana dengan bantuan AI.
